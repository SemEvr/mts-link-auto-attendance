# Автоподтверждение присутствия

Браузерное расширение и userscript с общим JavaScript-движком. Скрипт ищет элементы подтверждения присутствия по тексту и структуре страницы, нажимает найденную кнопку и сохраняет счётчик срабатываний.

Распознавание использует набор русских и английских фраз. Совместимость зависит от интерфейса конкретного сайта; отдельной интеграции с API каждой платформы в проекте нет.

## Установка расширения

### Chromium-браузеры

1. Скачайте и распакуйте репозиторий.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите корень проекта с `manifest.json`.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение».
3. Выберите `manifest.json` в корне проекта.

Временная установка действует до перезапуска браузера.

## Установка userscript

В менеджере пользовательских скриптов, например Tampermonkey или Violentmonkey, создайте новый скрипт и замените его содержимое файлом `dist/mts_link_autoconfirm.user.js`. Сохраните изменения и обновите нужную страницу.

Меню userscript содержит управление звуком и сброс счётчика. В расширении настройки доступны через значок на панели браузера.

## Настройки и работа

- Включение и выключение автоматического подтверждения.
- Звуковой сигнал при срабатывании.
- Всплывающее уведомление на странице.
- Счётчик нажатий с возможностью сброса.

Расширение подключает скрипты ко всем доступным ему сайтам (`<all_urls>`) и использует `storage` для настроек. Поиск основан на эвристиках, поэтому возможны пропуски и ошибочные срабатывания. Счётчик показывает действия скрипта, а не подтверждённую сервером посещаемость.

## Разработка

Требуется Node.js с npm. Внешние зависимости в `package.json` не объявлены.

```sh
npm run check
npm run build
```

Первая команда проверяет синтаксис JavaScript, вторая собирает userscript из общего движка и адаптера. Файл в `dist/` следует обновлять сборкой.

| Путь | Назначение |
| --- | --- |
| `manifest.json` | Настройки браузерного расширения |
| `src/presence-core.js` | Поиск элементов, обработка нажатий и уведомления |
| `src/presence-content.js` | Подключение движка к расширению |
| `src/control-panel.*` | Интерфейс настроек |
| `src/userscript/userscript-adapter.js` | Адаптер менеджера пользовательских скриптов |
| `build-userscript.js` | Сборка userscript |
| `dist/mts_link_autoconfirm.user.js` | Результат сборки |
